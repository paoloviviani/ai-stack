# Brief: i18n extraction slice (Cerea)

Repo /home/ubuntu/workspace/Cerea (public). You convert one slice of the UI to Paraglide messages. English only (owner): base locale `en`, plus the generated `en-XA` pseudo-locale.

Read first: AGENTS.md "Translations", `docs/writing.md` (wording rules and kept terms: the agent/Code area keeps its technical vocabulary), `scripts/i18n-check.mjs` (`CONVERTED` allowlist), `messages/en.json`, and how `src/routes/settings` was converted (the pilot), including `<Rich>` for messages with markup and `src/lib/i18n/format.ts` for dates/numbers.

Setup/rules:
- `git fetch origin && git worktree add -b <branch> /home/ubuntu/workspace/Cerea-wt-<short> origin/main`; work only there; `npm ci` in the worktree (no lock).
- `export TMPDIR=/var/tmp/<short>-tmp && mkdir -p $TMPDIR`.
- NEVER `git stash`, never `git commit --no-verify`. No AI attribution trailers. Push the branch only, no PR, never main. No nested sub-agents.
- `flock /tmp/heavy.lock` only around Playwright and production builds. At most one local e2e run per spec you touch; CI judges the rest.
- Flakes: reproduce with a component test that forces the race, at most 3 e2e repeats.

The work:
1. Move every user-facing string in your slice's files (templates, attributes `title`/`placeholder`/`aria-label`/`alt`/`label`, toasts, user-visible error text, empty states, and the `.ts` helpers your components use for display text) into `messages/en.json` under your namespaces only. Keep the current wording exactly (it was just reviewed by the owner); don't reword. Plurals and interpolations through Paraglide variables, never string concatenation.
2. Dates, times and numbers through `src/lib/i18n/format.ts` (the report lists browser-locale `toLocaleString` spots per area).
3. Add your directories to `CONVERTED` (one entry per line). Mark the rare must-stay-literal line with `i18n: literal` and a reason.
4. Insert keys in place, alphabetically within your namespace, never appended at the end of the file, so parallel slices merge cleanly. Never hand-merge `messages/en-XA.json`: run `npm run i18n:pseudo`.
5. Tests: existing tests must keep passing with English unchanged. Add one component test per major screen rendering in `en-XA` and failing on any visible unbracketed word (follow `src/routes/settings/application/page.svelte.test.ts`).
6. Before handing back: merge origin/main into the branch (regenerate en-XA, re-run i18n:check), then `npm run lint` (includes i18n:check), svelte-check, and the client tests of the converted directories. Report: branch, commits, string counts, anything left literal and why.

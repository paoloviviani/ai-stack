# Box rules (paste into every worker brief)

- **Box:** 5 cores / 20 GB, shared. At most 3 workers. Workers never spawn sub-agents.
- **Heavy jobs** (docker builds, `npm run build`, the full client vitest, Playwright/e2e): `flock -n /tmp/heavy.lock.a CMD || flock /tmp/heavy.lock.b CMD`. Never nest locks; `kit/dev/build.sh` locks itself (set its `BUILD_LOCK` to a slot instead).
- **Stacks:** run `docker compose ls` first. Use your own `-p` and non-colliding ports (80, 443, 8100, 8180 are taken). Take `flock /tmp/heavy.lock.x` for compose up/down.
- **The live stack** `/home/ubuntu/stack` (project `cerea`) serves real users. Never touch it, its `.env`, containers, volumes or networks. Don't touch `cerea-test` or `uireview` unless the brief says so. Allowed prunes: `docker image prune` (dangling) and `docker builder prune -f`.
- **Never** sudo, `git stash`, `--no-verify` or force-push. Never print secrets, API keys or `.env` values.
- **Temp files:** `export TMPDIR=/var/tmp/<task>-tmp` (mkdir it). Node: `export PATH=$HOME/.local/opt/node/bin:$PATH`, `NODE_OPTIONS=--max-old-space-size=3072`, vitest `--maxWorkers=3`. Python: `UV_PYTHON=3.13`.
- **Cerea vitest with Mongo:** `TEST_MONGODB_URL`, `--no-file-parallelism` (see AGENTS.md).
- **Playwright never points at external sites:** use local fixture servers only.
- **Commits:**
  - messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - push your branch with `git push -u origin <branch>`;
  - open a PR only if the brief says so; PR bodies end with "🤖 Generated with [Claude Code](https://claude.com/claude-code)";
  - never merge, tag or release.
- **UI copy:** say "users", not "people". Keep it topic-generic: no medical or other subject defaults.
- **Reporting:** what changed, each check run with its result, and each check not run, said as "not run".

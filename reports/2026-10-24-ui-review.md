# Cerea UI review — 2026-10-24

Source: the screenshot audit in `screenshots/2026-10-24-ui-audit/` (Cerea 0.23.1 build,
desktop 1440 and phone 390, light and dark, 6 accents × 3 tones) and the measured surface
colours. Ranked by impact for the effort. Each item is a proposal; nothing is built until the
owner picks it.

## 1. Background tones (owner: "the two greys are too similar")

Measured: Gray and Stone differ by ΔE 0.5 (light) / 0.8 (dark) on the page background, below
the just-noticeable difference (~1). They come from Tailwind's gray/slate/stone, which differ
only by a whisper of hue; Slate in dark mode swings to navy.

Proposal: define the tones ourselves on one shared lightness ladder, differing only in
temperature — **Neutral** (no cast), **Cool** (clearly cool, never navy), **Warm**
(paper/sand) — plus an optional **Tinted** (the neutrals take a faint hint of the chosen
accent). Rendered for comparison in `design/2026-10-24-tones/`.

## 2. Dark mode separation

Page, sidebar and composer sit 10/26/26 apart on 0–255 on Gray and Stone: the sidebar edge and
the workspace cards nearly merge with the background. Proposal: an explicit elevation ladder
(page < sidebar < card < composer, steady steps in OKLCH lightness) for every tone. Included in
the tone variants.

## 3. Text contrast (light mode)

Muted grey text (163,163,163 on 250 ≈ 2.4:1) is used for the sidebar date headers ("Today",
"This week"), the composer pills ("Web search") and the "Model: …" footer — below WCAG AA
(4.5:1). Some of it bypasses the tokens with hard-coded grey classes. Proposal: route secondary
text through two tokens (muted ≥ 7:1, faint ≥ 4.5:1) and replace the hard-coded classes; extend
the palette contrast test to them.

## 4. The accent barely shows in the chat

On the main chat view only the avatar, links and the send button carry the accent, so the six
accents look almost identical there. Proposal (pick any): the selected sidebar row tinted with
the accent; the composer's focus ring in the accent; the user's own message bubble faintly
tinted; the "Ran Python" / file card header icon in the accent. Subtle, but it makes the
choice of accent mean something where people spend their time.

## 5. One type scale for the chat

The Pystino console now has one role-based type scale with a guard test; the chat still mixes
sizes (sidebar rows small, message body large, pills and footer tiny). Bringing the chat onto
the same roles (title, heading, body, control, dense, small) is the biggest consistency win and
fixes the "tiny grey text" class of issues together with item 3.

## 6. Mobile defects found

- Tables and code blocks in a reply scroll horizontally with no cue — on a phone they read as
  clipped ("On / Ove / Unc"). Proposal: a fade/shadow at the scrolling edge.
- Project page on a phone: chat titles truncated to a few letters because "Remove from
  project" takes the width; the top bar says "New Chat" instead of the project's name.
  Proposal: icon button with a label in a menu; the project's name in the bar.
- Pair dialog on a phone: the `curl` command is clipped; on desktop the dialog runs off the
  viewport bottom. Proposal: wrap long commands (as done in the console) and cap the dialog
  height with its own scroll.

## 7. Smaller

- Workspace → MCP summary strip read "0 servers configured" next to "Your connectors (3)" in the
  audit; possibly an artefact of how the audit seeded connectors — to verify before fixing.
- Delete-project confirmation uses the browser's native `confirm()`, inconsistent with the
  app's own dialogs elsewhere.
